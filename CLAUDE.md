## MindPrint™ Framework

All AI generation for this project is governed by `/MindPrint_AI_Source_of_Truth.md`
in the project root. Before building or modifying any AI-powered tool, read this file.
It defines the language rules, profile truth tables, prohibited framings, and 
consistency checks that must be honored in every generation call.
